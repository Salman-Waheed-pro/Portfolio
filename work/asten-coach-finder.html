Workshop task 3 · Finding the right coach

Help an athlete pick one coach they are still training with eight weeks later

The finder is a matching tool with a search box attached. A short intake turns into filters and ranking inputs, every package is shown on one template, and a free intro call lowers the risk of choosing wrong. Everything on this page is built around that sequence.

Technical view

How data travels through the system

This assumes a modular monolith on Postgres, which is the simplest thing that handles 500 coaches. Boxes are modules, not separate deployments. Replace it with Asten's real stack once the company answers the questions at the bottom.

What each numbered arrow carries

  • 1. The intake answers as a query: sport, goal, years of training, where, schedule, gender preference, language, budget, sort.
  • 2. The API validates it and calls search and ranking with a typed filter object.
  • 3. One SQL query applies the hard filters and returns candidate coaches with their computed stats.
  • 4. Facet counts and the top results come from cache when the same filters were run recently.
  • 5. Package rows for the returned coach ids are fetched in one batch, with price per week worked out.
  • 6. A contact request creates a thread and shares the intake summary only after the athlete agrees.
  • 7. The worker recomputes response time, rating, rebooking and the accepting flag, and writes them to coach_stats.

The search call

GET /api/coaches/search
  ?sport=running&where=tampere&inPerson=0
  &years=1-3&goal=first-race&sched=evenings
  &gender=any&lang=any&budget=160&sort=match

200 {
  total: 34,
  facets: { sport:{...}, where:{...} },
  results: [{ coachId, score, parts:{fit,quality,
    response,start,boost}, why, card:{...},
    packages:[...] }],
  relax: { label, count } | null
}

Ranking runs in application code over the filtered rows, so weights live in config and can change without a migration. Every response logs a results_viewed event with the count and the zero-result flag.

Stretch question

Does it still work with five coaches? With five hundred?

It works at both sizes because the intake, the card and the package template stay the same. What changes is how much of the filtering and ranking the screen needs to show.

One thing holds at any size. Across several sports and cities, 500 coaches still means only a few per sport per city. Online coaching fills the gaps, so it is a first-class option from the first release.
